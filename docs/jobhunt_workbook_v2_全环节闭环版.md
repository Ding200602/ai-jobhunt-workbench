# 求职通 JobHunt Pro · 可执行工作流 v2.0
## 全环节闭环版（11 环节完整链路 + 专业加厚）

> 版本目标：把"从简历改写 → 收到线下面试邀请"做成**无缺口、可验收、每环有专业底座**的闭环。
> 相比 v1.0 的变更：
> 1. 补齐缺口环节 8（邀约确认闭环）与环节 10（终态验收标准）
> 2. 每个环节新增"专业底座 / 分支处理 / 常见错误 / 验收标准"四块，加厚专业性
> 3. 执行模式：**每环节完成出一份检查报告 → 用户确认 → 进下一环 → 全部完成后总验收**

## 环节 0：用户画像与素材挖掘

### 专业底座（加厚依据）
- 行为面试法 STAR（Situation-Task-Action-Result）：所有素材按四要素结构化，为后续面试做准备
- 招聘方决策心理学：HR 判断候选人靠"可验证信号"，无细节的自我评价=零信号
- 印象管理理论（Goffman）：简历本质是"有选择的自我呈现"，选择真实素材里的高信号面
- 认知访谈法（司法/心理领域）：用追问还原真实细节，防止用户随口编造导致面试穿帮

### 执行方法（细分）
1. 收集硬信息：学历/专业/在读时间/城市/手机/微信
2. 用 6 组开放问题挖掘软素材（成就感事件/自学经历/助人经历/课设项目/数据证据/他人评价）
3. 对每个素材追问三轮：做了什么→怎么做→结果可量化吗
4. 给每个素材打标签：可验证性（高/中/低）+ 可展开时长
5. 识别风险标签：用户声称但无细节支撑的→列入恶补表

### 分支处理
- 应届/在校：重点挖课设、比赛、自学产出
- 社招：重点挖最近一段工作的可量化成果
- 转行：重点挖"迁移能力"证据（学习速度、通用技能）
- 重返职场：空窗期里做的具体事（家庭管理/自学）也可转成能力证据

### 常见错误（来自真实踩坑复盘）
- ❌ 只收结论不收证据 → 简历出现"自学中/待确认"露馅
- ❌ 用户随口说"我做过 X"未追问细节 → 面试两分钟穿帮
- ❌ 素材不足时编造 → 违反红线，禁止
- ❌ 没问清求职类型（实习/全职）→ 平台选项都会填错

### 验收标准
- [ ] 素材 ≥ 8 条，每条有可展开细节
- [ ] 每条素材标注可验证性等级
- [ ] 画像报告含：优势标签、风险标签、适配方向
- [ ] 明确求职类型与城市（缺一不可）

## 环节 1：岗位定位与行情调研

### 专业底座
- 职业锚理论（Schein）：帮用户区分"想要"与"适合"
- 劳动经济学：岗位薪资 = 市场供需 × 技能稀缺度 × 城市系数，先看行情再定期望
- 岗位相似度匹配框架：JD 关键词共现分析（人工归纳即可）

### 执行方法
1. 三问交叉：想做什么 / 能做什么 / 市场要什么（产出交集）
2. 在目标城市搜索目标岗位 3-5 条真实 JD，提取共同关键词
3. 统计薪资区间分布，定出合理期望带（下限/中位/上限）
4. 输出主推岗位 ≤3 个 + 备选 ≤3 个
5. 明确"绝不投"的岗位类型（销售/电销/挂羊头等，写入过滤规则）

### 常见错误
- ❌ 期望薪资脱离行情 → 谈判无筹码
- ❌ 主推岗位太多 → 简历话术全拧巴
- ❌ 不查 JD 直接凭想象定位

### 验收标准
- [ ] 主推/备选岗位明确
- [ ] 薪资期望带给出（含依据）
- [ ] 绝投岗位清单明确

## 环节 2：简历策略与改写

### 专业底座
- ATS（Applicant Tracking System）工作原理：关键词匹配 + 格式解析 + 机器打分；约 35% 简历因格式问题被系统拒读
- 招聘决策心理学：HR 单份简历初筛约 6 秒，结果前置、动词开头、可扫读
- 去 AI 味语言学：AI 写作的 9 大特征（过度礼貌/排比/空洞形容词/被动句/完美无缺/模板收尾）
- 真实底线法：只放大真实，不虚构可背调事实（红线不可破）

### 执行方法
1. 按人群类型选适配策略（应届/实习/社招/转行/基层/重返职场）
2. 素材→简历句：每条用"动词 + 做了什么 + 方法 + 数据"重写
3. 量化三层法：基础数据 → 比较数据 → 衍生数据
4. 多版本管理：通用 PDF 版 + 各平台在线版 + 按目标岗位微调版
5. 去 AI 味六项自检 + 可背调性验证（每句能展开讲 2 分钟）
6. 排版规范：一页纸为主、PDF 保格式、文件名规范

### 常见错误
- ❌ 技能写得太诚实（"自学中/了解中"）→ 显得没底气；正确：熟练/精通 + 恶补表兜底
- ❌ 简历留内部标注 → 一眼 AI 代做
- ❌ 堆砌关键词 → ATS 反而降权
- ❌ 全篇空洞形容词无数据

### 验收标准
- [ ] 简历每个句子可背调、可展开 2 分钟
- [ ] 通过去 AI 味六项自检
- [ ] PDF + 在线版双格式产出
- [ ] 文件名规范：姓名_岗位_经验.pdf

## 环节 3：岗位搜索与初筛

### 专业底座
- 平台流量逻辑：BOSS"刚刚活跃"岗位回复率远高于僵尸岗；黄金时段（工作日 9-11 点/14-16 点）HR 在线率高
- 渠道矩阵：主平台 + 辅渠道（官网/内推/社群/校招/双选会）组合，不把鸡蛋放一个篮子

### 执行方法
1. 按主推岗位 × 目标城市列出搜索词组合
2. 全平台搜索，记录岗位：公司/岗位/薪资/JD 要点/发布时间/招聘人数
3. 初筛剔除明显不匹配（薪资倒挂/城市不符/方向偏差）
4. 输出候选清单，等待环节 4 验真

### 常见错误
- ❌ 只看薪资不看匹配度 → 投了也白投
- ❌ 只搜一个平台 → 漏掉大量机会
- ❌ 不记发布时间 → 投了僵尸岗不自知

### 验收标准
- [ ] 候选岗位清单（含链接、薪资、发布时间）
- [ ] 三城/目标城市均有覆盖

## 环节 4：公司验真与过滤

### 专业底座
- 工商登记法规：合法用工主体必须可查（国家企业信用信息公示系统）
- 劳动法/社保法：试用期须缴社保、不得收押金、不得扣押证件
- 用工陷阱实证研究：常见骗局模式（先交钱/培训贷/传销/高薪日结/骗取信息）
- 多源交叉验证法：单一信源不可靠，工商+投诉+员工风评+面试反问四源交叉

### 执行方法（五层扫描）
1. 平台层：查职位本身异常（薪资异常宽/诱人话术/长期大量挂岗）
2. 工商层：企查查/天眼查/国家公示系统查成立时间/注册资本/参保人数/涉诉
3. JD 层：查岗位描述是否挂羊头（名称 vs 实际职责）
4. 沟通层：观察 HR 是否回避公司名/地址/催加微信/非工作时间邀约
5. 合同层：入职前核对合同条款（此层延伸到环节 9 之后）

### 分级输出
- 🔴 必弃（直接不投）：收费陷阱/培训贷/传销特征/工商查无/欠薪投诉≥3
- 🟡 谨慎（用户二次确认）：规模过小/成立<1年/匹配度<60%/薪资低于均值20%
- 🟢 可推进：信息透明可查

### 验收标准
- [ ] 每个候选公司均有工商查询动作记录
- [ ] 三名单（通过/谨慎/必弃）明确
- [ ] 必弃原因标注信源

## 环节 5：薪资计算与估值

### 专业底座
- 社保法/个税法：五险一金个人比例、基数上下限（当地社平 60%–300%）、个税累进税率表
- 薪资结构拆解框架：税前≠到手，总包≠现金；区分月薪/年终奖/补贴/福利/期权
- 谈判锚定效应（心理学）：先了解对方预算再报期望，避免被低锚

### 执行方法
1. 每个通过岗位，取 JD 薪资中位为谈判基准
2. 查目标城市社保基数上下限与公积金比例（不背死比例）
3. 分步计算：五险一金个人扣款 → 个税 → 到手 → 加补贴 → 估算年终 → 总包
4. 输出每岗"到手月薪 + 总包结构"表
5. 标出薪资陷阱（含税口径不清/总包注水/最低基数缴社保）

### 验收标准
- [ ] 每个岗位有"税前→扣款→到手→总包"完整算式
- [ ] 列明计算假设（比例来源/是否含专项扣除）
- [ ] 标注需向 HR 确认的关键参数

## 环节 6：打招呼与话术准备

### 专业底座
- 会话含意理论（Grice 合作原则）：信息量恰到好处、相关、清晰、真实
- 礼貌理论（Brown & Levinson）：不过度礼貌（疏远），也不失礼（冒犯），用"轻松但尊重"的中间态
- 口语化特征研究：真人发消息=短句、有语气词、有具体指向、偶尔省略主语
- 说服心理学：一条消息只求一个动作，诉求单一才有效

### 执行方法
1. 按场景（首次打招呼/回复简历请求/已读不回/催面/面后跟进）各备 2-3 个变体
2. 每个变体结合真实岗位信息改写（JD 里的具体词）
3. 每条话术过四问：发给谁/在哪个环节/想让对方做什么/自夸了几句
4. 过"禁词表"：贵司/非常感谢/期待您的回复/综上所述等

### 验收标准
- [ ] 每条话术有岗位针对性（不含空泛万能句）
- [ ] 每条 ≤60 字（打招呼场景）
- [ ] 通过禁词检查

## 环节 7：投递执行与状态追踪

### 专业底座
- 平台风控机制认知：短时间高频投递/相同话术群发会被静默拦截（实测教训）
- 投递节奏理论：精投 5-10 个/天 优于海投 50 个；黄金时段投递
- 数据看板方法：投递状态四态模型（已投→已读→回复→约面），逐岗追踪

### 执行方法
1. 每天按"精投名单"执行投递（节奏随机化，防风控）
2. 每个岗位记录：投递时间/打招呼话术版本/当前状态
3. 实时更新看板：已投/已读/回复/约面 四栏
4. 每轮投递结束生成当日报告

### 常见错误（来自真实踩坑复盘）
- ❌ 短时间连投 17 岗 → 前 3 个发出后全被风控静默拦截
- ❌ 同一段话术群发 → 触发反垃圾
- ❌ 投完不记录 → 忘了跟进、重复投

### 验收标准
- [ ] 投递节奏符合防风控要求（分时段、随机化）
- [ ] 看板状态实时准确
- [ ] 当日报告生成

## 环节 8：对话推进与简历发送

### 专业底座
- 关系维护理论：已读不回的补刀 = 给台阶 + 给新钩子（带信息增量），不是催问
- 印象整饰理论：每次回复都在更新对方对你的判断——回复快、有针对性、不纠缠 = 靠谱信号

### 执行方法
1. 对方回复 → 1 小时内响应（平台活跃度加权）
2. 对方要简历 → 发 PDF + 一句简短说明（不附长文）
3. 对方已读不回 ≥3 天 → 补一条带新信息的消息（最多补 2 次，之后停）
4. 每次关键对话记录到会话推进表
5. 对话中识别危险信号（催加微信/收费/含糊）→ 启动环节 4 复核

### 验收标准
- [ ] 会话推进表实时更新（每岗一条）
- [ ] 危险信号已识别并复核
- [ ] 无轰炸式催促行为

## 环节 9：面试邀约确认与登记（本版补齐）

### 专业底座
- 邀约失约成本理论：线下面试是双方资源的承诺，需在口头确认后 24 小时内固化细节
- 承诺一致性原则（Cialdini）：让对方给出明确时间 = 提高对方履约概率
- 防"口头约面变没影"：缺要素的邀约不是有效邀约

### 执行方法
1. 收到面试邀约 → 立即确认四要素：**时间 / 地点（或线上会议链接）/ 面试岗位 / 面试官（或联系渠道）**
2. 四要素缺失 → 用话术补齐：「收到～方便确认下具体时间和地点吗？我这边安排下」
3. 确认后 24 小时内回执一次（表示重视 + 留证据）：「已确认，周X 下午 X 点，X 地，找 X 面试官，我会准时到」
4. 登记到邀约看板：公司/岗位/时间/地点/联系人/状态（已确认/待确认/已取消）
5. 面试前一天晚上确认一次（防止临时变更）：「明天下午的面试确认没问题，我会准时到～」

### 验收标准
- [ ] 邀约登记卡四要素齐全（时间/地点/岗位/联系人）
- [ ] 有 24 小时内回执记录
- [ ] 面试前 1 天有确认动作

## 环节 10：终态验收（收到线下面试邀请）（本版补齐）

### 验收定义
**"收到线下面试邀请" = 用户手中有一张满足四要素 + 双确认的线下邀约登记卡。**

四要素：
1. 具体时间（年月日 + 时刻）
2. 具体地点（公司地址/会议室/路线可查）
3. 岗位名称（与投递岗位一致）
4. 联系人/面试官（有姓名或 HR 渠道）

双确认：
1. AI 侧确认：邀约信息已完整登记到看板
2. 用户侧确认：用户核对该卡片信息无误

### 总验收报告模板

```markdown
# 求职全流程 · 总验收报告

## 验收结论
- 流程终点：✅/❌ 已收到线下面试邀请
- 邀约登记卡：公司 / 岗位 / 时间 / 地点 / 联系人

## 各环节检查汇总
| # | 环节 | 完成状态 | 检查结论 | 关键产出 |
|---|------|:---:|------|------|
| 0 | 画像与素材 | ✅ | 通过/不通过 | |
| 1 | 岗位定位 | ✅ | 通过/不通过 | |
| ... | | | | |

## 遗留问题
| 问题 | 影响 | 建议 |
|------|------|------|
| | | |

## 下一步建议（录用后延伸）
面试准备 → 谈薪 → 入职避坑（见延伸模块）
```

### 验收标准
- [ ] 四要素齐全的线下邀约登记卡已生成
- [ ] 用户已核对并确认卡片信息
- [ ] 11 个环节检查结论全部为"通过"或已说明例外

## 执行模式（每环节交付格式）

**每完成一个环节，AI 向用户输出一份《环节检查报告》**：

