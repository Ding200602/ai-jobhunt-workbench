# 求职实操手册 v2：从岗位过滤到线下面试全流程（2026 版）

> v2 修订说明：针对"投递前必须分清骗子公司、销售/文员等岗位不能投、对话要有人味"三项要求，重写第 1 章（岗位过滤+公司验真）与第 3 章（人味话术），补充 2026 年人社系统通报的真实骗局案例。本手册可直接用于 BOSS 直聘实操与求职视频素材。

---

## 第 1 章 投递前的两道筛子（本版重点）

> 先筛岗，再筛公司。两道都过了，才值得你花时间沟通和投简历。销售、电销、文员、挂羊头岗位，直接划走，不浪费一个字。

### 1.0 先立人设：你是谁，要什么

**用户定位（默认设定）**：技术向/专业向求职者（开发者、设计师、运营专家等有一技之长的角色）。目标是**技术/专业岗位**，不是"随便找份工作"。
**因此铁律**：凡以销售提成为核心、以打杂跑腿为核心、或以"无门槛培训"为核心的岗位，与你的定位冲突，**一律不投**。

### 1.1 岗位过滤器：哪些岗位直接划走

**黑名单 A——名称即死（看到就不点）**：
- 销售代表 / 销售专员 / 电话销售 / 课程顾问 / 咨询顾问(无技术方向)
- 推广专员 / 地推 / 招商专员 / 业务员 / BD(无技术背景)
- 文员 / 行政文员 / 资料员 / 内勤 / 前台 / 客服
- 电销 / 回访专员 / 售后话务
- 储备干部 / 综合内勤 / 人事助理 / 管培生(说不清轮岗的)

**黑名单 B——名称像正经岗，实为挂羊头（需进一步核实）**：

| 表面岗位 | 常见真实面目 | 穿帮点 |
|---|---|---|
| 运营专员/社群运营 | 卖课/卖货，拉人成交 | 问"工作内容"，答"维护客户群、沟通成交" |
| 新媒体/剪辑实习生 | 招转培，卖培训课 | "零基础可入职""带薪培训"→ 面试让你报班交钱 |
| UI/设计助理 | 同上，培训贷重灾区 | 贬低你作品 → 推荐实训 → 帮办分期贷款 |
| 人事/行政专员 | 变相招销售 | 面试说"岗位招满，先做销售试试" |
| Java/前端等开发岗 | 皮包/外包刷人头 | 不问技术栈，只谈"能吃苦有冲劲、服从安排" |
| 经理/总监助理 | 电销跟单 | 无具体职责描述，全靠"学习机会多" |

**验证三问（对方含糊即默认假岗）**：
1. 这个岗位每天最核心的三件事是什么？
2. 团队里同样职级的有几个人？
3. 试用期考核什么产出？

### 1.2 公司验真：五层信号扫描

> 资料来源：国家企业信用信息公示系统(gsxt.gov.cn)、天眼查/企查查、BOSS 官方防骗指南、多地人社局通报。

**第一层：职位页信号（30 秒排除法）**
- 同行业同岗位市场 4–6K，它标 8–15K → 高薪钓鱼，90% 电销/催收/地推外包
- 福利堆砌：无脑标"月休 8 天、双休不加班、包住、无责高薪、躺赚" → 噱头
- JD 空洞：不写职责、不写技能要求，只写"性格开朗、抗压即可、男女不限、零基础带薪培训" → 本质变相招销售或卖课
- 岗位常年挂出超 3 个月 → 僵尸岗/广告岗/薪资虚假

**第二层：工商信号（企查查/公示系统 2 分钟核实）**
- 成立时间 <6 个月 → 风险高
- 参保人数为 0 或长期个位数 → 家庭作坊/空壳（宣称百人团队但参保 5 人 = 必有问题）
- 实缴资本为 0、认缴画饼 → 实缴 ≥100 万才算基本实力
- 劳动纠纷、欠薪、行政处罚记录多 → 直接排除
- 注册地：居民楼/商住两用公寓 → 慎入；正规企业多在甲级写字楼

**第三层：聊天信号**
- 不筛简历、疯狂群发；秒回狂催"今天能来面试吗/急招/名额有限" → 刷面试 KPI
- 不问经历不问技能，只催到场 → 流水线招人
- 刚聊两句就让你加微信/下载陌生 App/转站外 → 高危
- 邀约地址模糊："到 XX 酒店/咖啡馆" 或频繁更换地点 → 高危

**第四层：面试现场信号**
- 地点临时变更到酒店、咖啡馆、居民楼
- 不谈业务细节，只谈"格局、梦想、财富自由"
- 先贬低你能力基础差，再推销"岗前实训/课程"，还主动帮你办分期贷款 → **招转培，立刻走人**
- 任何名义收费（建档/服装/押金/体检/培训费）→ 招聘收费违法，拒绝并举报
- 面试带行李、异地派人接、只问家庭情况 → 传销特征，脱身并报警

**第五层：合同与法务**
- 只口头承诺不给书面合同、或"两份薪资"阴阳合同
- 让你注册个体工商户/签合作协议规避社保
- 扣身份证/毕业证原件
- "保录/直签/交钱打点进国企" → 纯诈骗

### 1.3 真实案例库（2025–2026 官方通报）

1. **招转培 1.88 万实训贷案（国际在线/人社系统通报）**：北京某传媒公司招"运营助理"，面试通过后口头承诺月薪 8000，但不签劳动合同，以"入职需实训"为由诱导签《实训咨询服务协议》收费 1.88 万。求职者无力支付，被引导在小贷平台办理分期贷，月还 1777 元。→ **只要出现"先交钱培训才能入职"，立刻停止接触，不付款、不贷款，保留聊天记录并举报。**
2. **假冒知名企业收"打点费"案（北京警方 2026.8 通报）**：团伙假冒知名企业虚假招工，向求职者收 3 万–15 万"打点费"，租大厦办假面试、签假《培训协议》《拟录协议》，安排假实习地点稳住受害者。→ **凡说"特殊渠道、内部关系、交钱保录"全是诈骗，直接报警。**
3. **黑中介转手案（2026 整治通报）**：某人力资源公司无许可证，以"高薪电子厂"名义招人，求职者到厂发现并无招聘计划，改约酒店面试收被褥费、车费后层层转手，最终岗位待遇远不如广告。→ **看平台方是否公示《人力资源服务许可证》；缴费前停手。**
4. **"人事行政文员"劝转销售（求职者高频踩坑）**：到面告知"岗位招满，看你沟通能力强先做销售/信贷/保险"。→ **合同岗位与应聘岗位不一致 = 岗位美化，当场拒绝。**

### 1.4 投递策略与平台规则（同 v1，保留要点）

- 双通道：只点"申请职位"不够，必须点"马上沟通/立即沟通"开启对话
- 单日 15–25 个高质量对话；应届生 10–15/天，跳槽 15–20/天，转行 ≤10/天
- 黄金时段 09:30–10:30 / 14:00–15:00 / 20:00–22:00；5 分钟内回消息最佳
- 养号禁忌：短时群发同话术、频繁切设备/IP、简历造假

## 第 2 章 在线简历优化（要点）

- 头像白底/蓝底正装照；昵称「姓名-岗位-核心优势」；期望薪资填区间，禁"面议"
- 经历用「动词 + 成果 + 数据」；技能标签 5–8 个强相关词，对齐 JD 关键词
- 应届生把课程项目、社团、**大赛经历**（如 AI 小程序设计大赛）包装成相关经验
- 完整度 100%；每周微调 2–3 个关键词触发重新索引；单岗位只投一次

## 第 3 章 人味沟通话术库（本版重点）

### 3.0 为什么旧话术不行

旧版模板："您好，应聘贵司『Java 开发工程师』，4 年 SpringCloud 经验……盼详聊。"
问题：HR 一天收几十条一模一样的格式，一眼判定海投/AI 生成，直接划走。"贵司、盼详聊、与岗位高度匹配"都是**书面套话**，真人微信聊天不会这么说。

### 3.1 人味三原则

1. **短句、口语、像发微信**：别写小作文，3–5 句到点收。
2. **有具体针对**：哪怕只是"看到要求 React，我主力就是它"也足够；万能话术 = 无话术。
3. **不卑不亢**：不舔（"求给个机会"），不装（"非我莫属"），正常成年人聊天。

### 3.2 对照改写表（AI 腔 → 人味版）

| 场景 | AI 腔（不要） | 人味版（用这个） |
|---|---|---|
| 打招呼-通用 | 您好，应聘贵司『XX』岗位，本人拥有 X 年经验，盼详聊。 | 您好，看到贵司在招【XX】。我做了 X 年相关，简历发您了，方便的话聊聊？ |
| 打招呼-应届 | 我是 XX 大学 XX 专业应届生，实习期间……熟悉内容策划与数据复盘。 | 您好～我是 XX 大学 XX 专业应届生，实习独立做小红书，最高单篇 85 万曝光。看到咱岗位挺对口，主动来问问～ |
| 打招呼-经验者 | BOSS 好，我有 3 年 XX 经验，主导从 0 到 50 万…… | 老板好，我做了 3 年 XX，之前在 XX 把私域从 0 做到 50 万粉、转化提了 42%。看咱在招这块，想了解下现在做到哪步了？ |
| 已读不回 | 您好，注意到您已查阅消息，补充：我可随时配合…… | 您好～看您读过消息了，估计在忙。补一句：需要笔试或作品集我随时配合，您先忙～ |
| 约线下面试 | 如果您觉得我比较合适，我们能否约个时间，线下当面沟通一下？ | 要不咱们约个时间当面聊？我这周三下午或周四上午都行，您看哪天方便？ |
| 被问薪资 | 结合我过往经验、岗位要求及咱们城市行情，希望薪资符合公司标准…… | 市场行情我大概了解，主要还是看这个岗的预算范围，方便先透露下吗？合适咱再往下聊。 |
| 被压价 | 理解公司薪酬体系，结合我能独立接手核心工作、减少磨合成本…… | 理解公司有薪酬体系，不过这岗我基本能直接上手、不用多磨合，希望能在 XX 左右，您看能再争取下吗？ |

### 3.3 进阶：让对话"活"起来

- **顺着对方的话接**：HR 问"你现在住哪"，别只答地点，补一句"所以通勤很方便，随时能到岗"。
- **适当放一点个人色彩**：作品、比赛、博客、开源项目，都是话题抓手（适合技术向求职者）。
- **不用句号轰炸**：多用短句、口语词（"咱""您先忙""不着急"），但保持分寸，别卖萌过度。
- **已读不回超过 1 天可换个角度再问一次**：从"我补充了什么"变成"我有个问题"（如"顺便想问下这个岗现在还在推进吗"），降低 HR 回复压力。

### 3.4 其余通用话术（v1 保留精炼版）

- **鸽面/拒面**：非常感谢认可，因 XX 原因不能赴约，很遗憾。希望以后有机会再合作。
- **在职状态**：如实说"目前在职看机会"；到岗时间：在职可协商 1 个月内交接，离职随时到岗。

## 第 4 章 线下面试全流程（要点）

- 面试前：三维调研（业务痛点/竞品/团队）、备 3 个 JD 核心要求案例、30s/1min/3min 自我介绍、纸质简历 2–3 份+作品集、提前 15 分钟到
- 项目深挖用 STAR；离职原因正向；规划 1–2 年骨干 → 3–5 年负责人
- 反问环节（加分项）：岗位核心工作与短期目标 / 团队配置与培养方向 / 试用期考核标准
- 24h 内感谢信；3–7 天未通知礼貌询问；接 offer 前确认薪资架构/试用期/五险一金/发薪日/单双休

## 第 5 章 防骗与法律红线（求职必背）

### 5.1 一句话原则

> **凡是让你先交钱的招聘，99% 是骗局。** 正规公司招人是因为缺人干活，不是为了赚你的培训费。招聘收费 = 违法。

### 5.2 常见陷阱识别表

| 陷阱类型 | 识别信号 | 正确处置 |
|---|---|---|
| 收费陷阱 | 押金/保证金/培训费/服装费/体检费/建档费 | 拒绝并举报（12333） |
| 招转培/培训贷 | 面试贬低 → 推销岗前培训 → 帮办分期贷款 | 立即走人（案例：1.88 万实训贷） |
| 付费内推/保录直签 | "交 X 万保证进国企/大厂""内部打点" | 纯诈骗，报警（案例：假冒企业收 3–15 万） |
| 岗位美化 | "市场经理"实为销售；面试劝转销售/信贷/保险 | 合同与应聘不一致不签 |
| 个体户规避社保 | 注册个体工商户签"合作协议" | 仍属劳动关系，可举报 |
| 假试用真使用 | 超长/重复试用、不给社保、期满辞退 | 违反法定试用期约定无效 |
| 无薪试岗 | "前 3–7 天试岗期没工资" | 违法，拒绝 |
| 扣证件 | 以办社保/工资卡名义扣身份证毕业证原件 | 只出示，复印件注明用途 |
| 传销/异地接人 | 酒店/居民楼面试、带行李、派人接、只问家庭 | 脱身并报警 |
| 阴阳/空白合同 | 口头承诺、拒签书面合同、两份薪资合同 | 白纸黑字才签 |
| 空壳洗钱/虚拟币 | "区块链/数字资产"包装、业务说不清 | 核实牌照，终止并报警 |
| AI 换脸冒充招聘 | 远程面试+线上签约要求转账缴费 | 官方渠道核实，拒绝线上转账 |

### 5.3 法定红线速查

- 试用期上限：合同 ≤1 年 → ≤1 个月；1–3 年 → ≤2 个月；≥3 年/无固定 → ≤6 个月；只能一次；<3 个月合同不得设试用期
- 试用期工资 ≥ 转正 80% 且 ≥ 当地最低工资（取高值）；试用期必须缴社保
- 违约金仅限专项培训服务期、竞业限制两种
- 招聘收费全违法，可拨 12333 / 12345 投诉

### 5.4 高危岗位名单（应届生尤其警惕）

AI 漫剧/短视频剪辑/设计实习生（招转培重灾区）、人事行政文员（劝转销售）、高薪低门槛"运营"、货运司机租车套路、保安中介费、直播培训费、居家兼职刷单（涉帮信罪）、异地外派、虚拟币"金融跨境"岗位。

### 5.5 遇到问题怎么办

- 求职陷阱/恶意解约 → 12333 或当地人社部门
- 人身安全受威胁 → 立即报警，保留聊天记录与转账凭证
- 保留证据：聊天截图、缴费凭证、合同文件、邀约记录
